# 电气故障大全（50条）

格式：现象 → 原因 → 处理 → 预防。适用于本码垛单元，同类设备可参照。

## A. PLC 类（1-13）

1. **现象**：CPU ERROR 灯红闪，无输出。**原因**：组态与实件不符或块未编译完整。**处理**：核对订货号，全项目编译后整体下载。**预防**：修改后执行“编译-下载-备份”三步不走样。
2. **现象**：输入指示灯不亮但元件动作。**原因**：1M/2M 公共端未接。**处理**：接好公共端并核对 PNP/NPN。**预防**：新柜上电前先量公共端电压。
3. **现象**：Q 点灯亮、负载不动。**原因**：该输出组 3L+/4L+ 电源未接。**处理**：补接组电源。**预防**：接线后按组做“灯-表-负载”三查。
4. **现象**：输入随机抖动。**原因**：与动力线伴走耦合干扰。**处理**：换屏蔽双绞分槽布线，输入滤波 20ms。**预防**：布线阶段执行强弱电间距 ≥200mm。
5. **现象**：PTO 无脉冲。**原因**：轴工艺对象未启用或报错。**处理**：查轴状态字与组态。**预防**：组态后先空载试脉冲再接驱动器。
6. **现象**：屏读不到变量。**原因**：IP 异网段或未开放访问。**处理**：统一网段并允许 PUT/GET。**预防**：调试初期固化网络表。
7. **现象**：断电计数丢失。**原因**：变量未设保持。**处理**：设保持属性。**预防**：计数/累计类一律保持型。
8. **现象**：扫描周期报警超时。**原因**：主循环任务过重。**处理**：高速逻辑移入循环中断。**预防**：新增功能前评估周期预算。
9. **现象**：输出点烧毁发黑。**原因**：感性负载未加续流二极管。**处理**：换点并加二极管。**预防**：所有继电器/阀线圈标配续流。
10. **现象**：程序下载后设备乱动。**原因**：在运行模式下载且未停止顺控。**处理**：急停后再下载。**预防**：规定“停机改程序”作业票。
11. **现象**：SF 灯亮模块找不到。**原因**：Profinet 设备名未分配。**处理**：TIA 分配名称后下载组态。**预防**：组态命名与现场标签一致。
12. **现象**：时钟跳变致记录错乱。**原因**：未配掉电时钟电池。**处理**：配卡并同步时间。**预防**：验收项加入时间同步检查。
13. **现象**：仿真正常现场异常。**原因**：仿真未模拟真实 IO 延时。**处理**：现场低速首验。**预防**：首调速度上限写入调试规范。

## B. 伺服类（14-26）

14. **现象**：方向信号给足电机不动。**原因**：SON 使能未通。**处理**：查 KA1 与急停串联回路。**预防**：使能链路接入点检表。
15. **现象**：驱动器过载报警电机烫。**原因**：机械卡滞或加减速过激。**处理**：排除卡滞、延长加减速。**预防**：装机手盘机构确认灵活。
16. **现象**：低速爬行抖动。**原因**：增益偏低。**处理**：调高位置环增益并自整定。**预防**：换负载后重做整定。
17. **现象**：使能即飞车。**原因**：编码器/动力相序错线。**处理**：急停，用原装编码器线重接。**预防**：上使能前手离急停、低速警戒。
18. **现象**：方向与指令相反。**原因**：DIR 逻辑未配。**处理**：改 P1-01 逻辑。**预防**：点动验证方向纳入首调项。
19. **现象**：高速丢步定位偏。**原因**：脉冲线干扰或过长。**处理**：改差分、缩短、加磁环。**预防**：脉冲线屏蔽单端接地入工艺。
20. **现象**：压限位仍继续走。**原因**：限位只进软件或未接 LSP/LSN。**处理**：接入驱动器硬限位。**预防**：软硬件双限位写入设计规范。
21. **现象**：回原点位置漂移。**原因**：原点开关抖动。**处理**：加滤波或换接近开关。**预防**：原点件纳入点检。
22. **现象**：制动电阻过热异味。**原因**：频繁启停超出电阻功率。**处理**：换大功率电阻或降频。**预防**：选型时按工况核算制动占空比。
23. **现象**：上电即显示欠压报警。**原因**：主回路缺相/电压低。**处理**：量 L1/L2 与断路器触点。**预防**：配电电压季度巡检。
24. **现象**：电机有嗡声不转。**原因**：堵转或 U/V/W 缺相。**处理**：断电量线通断与绝缘。**预防**：动力线压接每年紧固。
25. **现象**：电子齿轮比错送料距离不对。**原因**：脉冲当量计算错误。**处理**：按“1 脉冲=0.01mm”重算 P1-44/45。**预防**：当量参数锁定并记录台账。
26. **现象**：伺服就绪信号时有时无。**原因**：24V 电源裕量不足压降。**处理**：加粗干线或增电源。**预防**：电源负载率 ≤80% 设计。

## C. 机器人类（27-38）

27. **现象**：启动命令无效。**原因**：DI1 未收到或程序未 WaitDI。**处理**：示教器监视 DI 与程序指针。**预防**：握手信号表双方签字确认。
28. **现象**：抓取位置整体偏移。**原因**：TCP 标定误差或被动过。**处理**：重做 4 点法标定。**预防**：换工具即重标并记录。
29. **现象**：工件坐标系偏。**原因**：托盘移位。**处理**：3 点法重标 wPallet。**预防**：托盘定位挡块点检。
30. **现象**：碰撞检测报警停机。**原因**：路径与垛型干涉。**处理**：低速单步验证并修 Offs 层高。**预防**：程序改动后必须空载慢跑。
31. **现象**：夹爪不吸。**原因**：真空不足或 DO4 未映射。**处理**：查气源与 Signal 定义。**预防**：真空压力低报警联锁。
32. **现象**：上电即急停。**原因**：安全回路断（门/急停触点）。**处理**：查 XS 接口串联回路。**预防**：安全回路月度试验。
33. **现象**：机器人 DO 有 PLC 收不到。**原因**：DSQC652 供电未接或地址冲突。**处理**：补 24V、核对地址 10。**预防**：I/O 板初始化清单。
34. **现象**：程序停在等待步。**原因**：握手时序颠倒或信号粘连。**处理**：逻辑分析仪核时序。**预防**：命令一律脉冲式。
35. **现象**：运行抖动异响。**原因**：载荷参数与实际不符。**处理**：载荷辨识重设。**预防**：换夹具即做辨识。
36. **现象**：误碰安全区外停机。**原因**：World Zone 未按新垛型更新。**处理**：重设 superv zone。**预防**：垛型变更评审表。
37. **现象**：死循环在等待料。**原因**：光电常亮（残料遮挡）。**处理**：清料并对准。**预防**：检测位加装吹扫。
38. **现象**：电机过温报警。**原因**：节拍过快周期负载高。**处理**：优化等待段降占空比。**预防**：验收时做温升记录。

## D. 通讯类（39-50）

39. **现象**：ping 不通机器人。**原因**：网段不同/端口用错。**处理**：统一 192.168.0.x 并重启。**预防**：改 IP 后登记网络表。
40. **现象**：snap7 连接超时。**原因**：TSAP 错或保护等级。**处理**：TSAP 01 00/01 02 并开放访问。**预防**：调试账户固定配置。
41. **现象**：OPC UA 中断证书错误。**原因**：证书未信任过期。**处理**：重新受信。**预防**：证书有效期纳入巡检。
42. **现象**：屏变量时断时续。**原因**：水晶头氧化/交换机差。**处理**：重做接头换工业交换机。**预防**：网线走线避开动力电缆。
43. **现象**：日志重复刷屏。**原因**：报警未做边沿。**处理**：上升沿采集加防抖。**预防**：报警开发规范。
44. **现象**：整线偶发停 1~2s 自恢复。**原因**：握手抖动+超时设计过长。**处理**：缩短超时加滤波。**预防**：时序联调阶段抓包留档。
45. **现象**：广播风暴网络慢。**原因**：网内环路。**处理**：拆环或启 STP。**预防**：网络拓扑图制度。
46. **现象**：上位机时间戳跳变。**原因**：本机与 PLC 时钟不同步。**处理**：NTP 统一。**预防**：装机统一授时源。
47. **现象**：CSV 乱码。**原因**：Excel 与 UTF-8 兼容问题。**处理**：utf-8-sig 写入。**预防**：导出模块统一编码。
48. **现象**：采集丢点。**原因**：轮询周期小于线程调度。**处理**：改事件/回调或加缓冲。**预防**：负载测试纳入验收。
49. **现象**：远程桌面连上即断网。**原因**：双网卡路由冲突。**处理**：metric 与绑定网卡。**预防**：上位机网络方案评审。
50. **现象**：机器人与 PLC 抢写同一变量。**原因**：职责边界未定义。**处理**：明确“PLC 权威、机器人只报状态”。**预防**：接口控制文档(ICD)制度。
