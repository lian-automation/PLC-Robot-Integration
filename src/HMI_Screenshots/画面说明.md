# MCGS 触摸屏画面说明(TPC7062Ti)

## 画面1：主界面(索引 0)
显示运行状态、模式、计数与三色指示，可跳转其他画面。

```
┌──────────────────────────────────────────┐
│  PLC-Robot 码垛演示线      2026-08-16 10:20│
├──────────────────────────────────────────┤
│  运行状态: ●自动运行   模式: 自动           │
│  伺服: ●使能  机器人: ●自动  夹爪: ●吸合    │
│                                          │
│   当前计数:  12 件        目标: 24 件       │
│   层数: 2 / 4            节拍: 18.5 s      │
│                                          │
│   [ 启动 ]   [ 停止 ]   [ 报警复位 ]        │
│                                          │
│   → 手动调试   → 报警中心   → 参数设置      │
└──────────────────────────────────────────┘
```
元件：状态灯关联 M 区状态字；计数/节拍为 PLC 传上的实时值；“启动/停止”为瞬动按钮，写 M 位由 PLC 逻辑确认执行，防止屏死机误发命令。

## 画面2：手动调试界面(索引 1)
仅供调试，进入需密码(权限等级≥2)，并强制 PLC 切到手动。

```
┌──────────────────────────────────────────┐
│  手动调试               [返回主界面]        │
├──────────────────────────────────────────┤
│  伺服使能: [ ON ]  [ OFF ]    状态: ●ON    │
│                                          │
│  伺服点动:  [◄ 反转 ]    [ 正转 ►]         │
│  点动速度:  20 kHz   ▼                    │
│  [ 回原点 ]          原点: ●已到位          │
│                                          │
│  信号强制测试(仅调试):                     │
│  [ 三色灯测试 ]  [ 蜂鸣器测试 ]             │
│                                          │
│  ⚠ 手动模式机器人请用手动操纵,本屏不控制    │
└──────────────────────────────────────────┘
```
元件：点动按钮为“按下置位/松开复位”；速度用下拉框 10/20/50kHz；回原点按钮带确认弹窗，防止误触。

## 画面3：报警界面(索引 2)
滚动报警窗口 + 当前报警条，任何画面有报警时底部红条闪烁并可一键跳转。

```
┌──────────────────────────────────────────┐
│  报警中心        当前报警: 1 条  [返回]      │
├──────────────────────────────────────────┤
│ 时间            报警内容        状态        │
│ 10:18:03  伺服过载报警        ●活动        │
│ 09:42:11  机器人允许抓取超时   已恢复       │
│ 09:15:47  安全门打开          已恢复       │
│ 08:50:02  与机器人通讯超时    已恢复       │
│                                          │
│  [ 报警确认 ]  [ 报警应答 ]  [ 历史导出 ]   │
└──────────────────────────────────────────┘
```
元件：MCGS“实时报警”构件，报警位对应 PLC DB 报警字；活动报警红色、恢复后灰色；历史报警按 U 盘导出 CSV，便于现场追责分析。
