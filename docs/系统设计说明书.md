# 系统设计说明书

**项目名称**：PLC-Robot-Integration-Demo（伺服输送 + ABB 机器人码垛单元）
**版本**：V2.1　**日期**：2026-08-16　**定位**：个人学习/作品集项目（PLCSIM + RobotStudio 虚拟调试交付）

## 1. 概述与需求分析

### 1.1 项目背景
演示单元需在输送线末端实现物料自动整理码垛：伺服驱动的输送线将料箱按节拍送至抓取位，机器人抓取后按 3×4×4 垛型码放到托盘，操作工只需换托盘与监控。项目同时承担教学演示任务，需保留完整工程文档。

### 1.2 功能需求
F1 手动模式：伺服点动、使能控制、回原点、指示灯测试，供调试与维修使用；
F2 自动模式：一键启动后无人干预连续码垛，满垛(48件)自动提示换托盘；
F3 故障处理：急停、安全门、伺服报警、机器人故障、送料/握手超时五类故障分级报警并可复位；
F4 数据监控：触摸屏显示状态与计数并可设参数；上位机记录电流/电压/温度并绘制曲线、导出报表；
F5 安全需求：急停与安全门经硬件安全链同时切断伺服使能与机器人运动，响应 <0.5s。

### 1.3 性能需求
节拍 ≤20s/件；伺服定位重复精度 ±0.5mm；通讯刷新 ≤200ms；连续运行可用率 ≥98%；启动成功率 ≥99%。

### 1.4 环境与约束
车间温度 0~40℃、粉尘一般；供电 AC380V/50Hz；预算与备件渠道决定选西门子+台达+ABB 组合；工期按 30 个调试日规划。

## 2. 系统架构

### 2.1 总体架构
三层结构：设备层（伺服输送线、机器人本体、传感器、夹爪）→ 控制层（S7-1214C 顺控 + IRC5 RAPID）→ 监控层（MCGS 触摸屏 + Python 上位机）。PLC 是唯一顺控权威，机器人只接受“启动/复位”两个数字量命令并回报“允许抓取/完成/故障”，上位机只读不控，保证安全责任边界清晰。

### 2.2 网络架构
八口工业交换机组建 192.168.0.x 网段：PLC=0.1、机器人=0.20（由默认 192.168.125.1 修改）、触摸屏=0.30、上位机=0.100。PLC↔屏走 S7comm（MCGS 内置 S7-1200 以太网驱动），PLC↔上位机走 OPC UA（证书信任列表管理），机器人命令走硬接线 I/O（实时性与安全性优于报文）。

### 2.3 信号流与握手时序
物料到光电(I0.7) → PLC 伺服送料 → 到位 → 等机器人 DO1“允许抓取” → PLC Q0.7 脉冲命令(600ms) → 机器人抓放（夹爪 DO4、真空反馈 DI）→ DO2“完成” → PLC 计数进入下一件。握手超时 30s 分级报警。

## 3. 硬件方案

### 3.1 供电与安全回路
主回路：AC380V 经断路器 QF0 → 伺服主回路（单相 AC220 经 QF1）与机器人控制柜独立供电。控制回路 DC24V 由明纬 S-100-24 供给。安全链：急停按钮常闭触点 + 安全门开关串联，同时串入伺服 SON 公共回路与机器人 XS 安全接口；急停辅助触点同时送 PLC I1.0 作状态指示（只指示、不参与切断，切断由硬件完成）。

### 3.2 I/O 分配（摘要）
DI：启动/停止/复位/手自动选择、正反限位、光电、急停反馈、安全门、机器人 DO1~DO3 回报、伺服 ALM/RDY，共 14 点；DO：脉冲 PUL+方向 DIR（Q0.0/Q0.4 成对）、伺服使能经 KA1、三色灯、蜂鸣器、机器人 DI1/DI2 命令，共 10 点。AI 两路：电流变送器、温度变送器（0-10V）。

### 3.3 伺服与机器人
台达 B2 750W 脉冲+方向控制，电子齿轮比按“1 脉冲 = 0.01mm”整定；限位采用**硬件接入驱动器 LSP/LSN + 软件限位双保险**。机器人 IRB1200 配 DSQC652 I/O 板（地址 10），夹爪电磁阀直接由机器人 DO4 驱动以保证 RAPID 程序自洽。

### 3.4 屏蔽接地
信号 0.5mm² 屏蔽双绞、动力 1.5~4mm²；屏蔽层单端接地（脉冲在驱动器侧）；信号与动力分槽 ≥200mm；PE 铜排接地电阻 ≤4Ω；中间继电器线圈并续流二极管。

## 4. 软件方案

### 4.1 PLC 程序结构
`src/PLC_Logic.scl` 三块：FB_ServoCtrl（使能/点动/限位互锁/报警锁存）、FB_PalletMain（8 步顺控状态机：待机→回原点→等料→送料→等允许→发命令→等完成→垛满）、FB_FaultHandler（优先级编码 + 首发故障锁存）。OB100 初始化、OB1 调用、工艺对象管轴 PTO。设计要点：停止/急停在状态机外层强制回 0 态，任何步内不“绕过”安全；发送给机器人的命令用脉冲式，避免信号粘连导致重复启动。

### 4.2 机器人程序结构
`src/Robot_Program.mod`：main 死循环等待 diPLCStart（30s 超时防死等）；rInit 挂接急停中断（ISignalDI→TRAP：StopMove+ClearPath）；rPalletize 三层 FOR 循环计算垛型，隔层 RelTool 旋转 90° 压缝；速度分 vHigh/vMid/vLow 三档 + 接近点先上后下策略；夹爪带真空反馈，超时 TPWrite 报警。TCP 用 4 点法标定（误差 <0.5mm），工件坐标系 3 点法。

### 4.3 触摸屏与上位机
MCGS 三画面：主界面（状态/计数/节拍）、手动调试（密码权限≥2、点动按钮按下置位松开复位）、报警中心（实时报警滚动 + U 盘导出 CSV）。上位机 Python：snap7/OPC UA 采集 → 滚动缓冲 → matplotlib 实时曲线 → CSV 历史 → 报表导出（均值/峰值/报警次数/可用率）。数据模拟器可在无 PLC 环境回放联调。

## 5. 通讯与数据设计
变量约定：MW10 电流、MW12 电压、MW14 温度、MW16 计数、MW22 故障码；报警位对应 M1.x。OPC UA 命名空间按“设备_信号”命名，采样 1s；历史数据按天分文件，保留 90 天；报表字段与验收指标一一对应，保证考核数据可追溯。

## 6. 调试流程（30 天规划，详见 logs/完整调试记录.md；全部在虚拟环境执行）
阶段一（D1~D6）图纸核对与柜内接线、安全链试验；阶段二（D7~D12）PLC 单机：下载、点动、限位、模拟信号；阶段三（D13~D18）伺服整定：电子齿轮、增益、回原点精度；阶段四（D19~D24）机器人：TCP/工件标定、空载路径、垛型验证；阶段五（D25~D28）联调：握手时序、超时与恢复、HMI/上位机；阶段六（D29~D30）带载考核 48h 与验收。每阶段有“通过判据”，不达标不得进入下一阶段。

## 8. 风险与对策
① 换切/换向引起电弧短路 → 死区时间 + 硬件互锁；② 真空吸着失败掉料 → 真空反馈 + 低速段 + 接近点策略；③ 通讯抖动误报警 → 边沿触发 + 防抖滤波 + 超时分级；④ 现场改线导致图实不符 → 核线记录 + 版本化管理，任何改动先改图后改线；⑤ 人员误操作 → 手动画面密码 + 命令脉冲式 + 复位不自动重启。
