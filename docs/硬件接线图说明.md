# 硬件接线图说明

> 本文档描述《PLC-Robot-Integration》的电气接线方案，作为原理图(EPLAN/CADe)的文字版底稿。
> 实际接线以随机手册端子定义为准，本文端子号适用于 S7-1214C DC/DC/DC、台达 ASDA-B2 750W、ABB IRC5(IRB1200)。

## 1. 供电与接地总则

- 系统由一台 24V/5A 开关电源(明纬 S-100-24)统一供控制回路，伺服主回路单独走单相 AC220V，经 2P 断路器(6A)隔离。
- 柜内设 PE 铜排，所有设备金属外壳、屏蔽层、门板接地线全部汇至铜排，铜排接大地，接地电阻 ≤4Ω。
- 控制电源(24V)与动力电源(AC220V/380V)分槽布线，间距 ≥200mm；交叉时垂直交叉，避免平行长距离伴走。
- 急停按钮(常闭)串入伺服 SON 公共回路与机器人急停回路，形成硬件安全链，不依赖程序。

## 3. 台达 ASDA-B2 伺服接线

**主回路(端子排，线径见第5节)：**
- L1、L2：单相 AC220V，经断路器+接触器，接触器线圈受急停安全链控制。
- L1C、L2C：控制电源，与 L1/L2 并接(必须同相)。
- U、V、W → 伺服电机动力线；PE → 电机外壳。
- 750W 及以下内置制动单元，频繁启停才外接制动电阻。

**CN1(控制信号，重点引脚)：**

| 信号 | 说明 | 对接 |
|---|---|---|
| COM+ | DI 公共阳极 | 接 24V(经急停常闭触点) |
| DI1(SON) | 使能 | KA1 常开触点 |
| DI5/DI6 | 正/反限位 LSP/LSN | 默认功能(P2.10~P2.17 可改) |
| PUL+/PUL-、DIR+/DIR- | 差分脉冲/方向 | PLC Q0.0、Q0.4 |
| DO1(ALM)、DO2(RDY) | 报警/就绪 | PLC I1.4、I1.5 |

- 脉冲命令设为“脉冲+方向”逻辑(P1-00)，PLC 侧 24V 脉冲可直接驱动光耦输入；频率高、线长 >2m 时优先差分接法。
- CN2 编码器线用原装电缆，禁止自行压接延长。

**CN3(RS-485)**：仅用于笔记本在线调参，不参与运行。

## 4. ABB 机器人 I/O 对接(DSQC652 板，16DI/16DO)

- 板卡 DeviceNet 地址拨码为 10，示教器“配置-DeviceNet-Industrial Network”下挂接。
- X1=DO1~8、X2=DO9~16、X3=DI1~8、X4=DI9~16，每个连接器自带 24V/0V 供电脚，由机器人控制柜供给。
- 信号对接表：

| 机器人信号 | 方向 | PLC侧 | 功能 |
|---|---|---|---|
| DI1 | 输入 | Q0.7 | 码垛启动 |
| DI2 | 输入 | Q1.0 | 复位 |
| DI3 | 输入 | 安全继电器辅助触点 | 急停联动(不经PLC) |
| DO1 | 输出 | I0.6 | 允许抓取(在安全位) |
| DO2 | 输出 | I1.2 | 码垛完成 |
| DO3 | 输出 | I1.3 | 机器人故障 |
| DO4 | 输出 | 直驱夹爪电磁阀 | RAPID 中 vacuum1 |

- 网络：八口交换机汇聚 PLC(192.168.0.1)、机器人(默认 192.168.125.1，需改为 192.168.0.20)、MCGS 触摸屏(192.168.0.30)，注意机器人改网段后示教器需重启生效。

## 5. 线径与屏蔽要求

| 回路 | 线径 | 电缆类型 |
|---|---|---|
| 伺服主回路/电机动力 | 1.5mm² | 屏蔽电缆 |
| AC220V 配电 | 1.5mm² | 普通护套 |
| 24V 电源干线 | 1.0mm² | 普通护套 |
| DI/DO 信号 | 0.5mm² | 普通护套(柜内) |
| 脉冲/方向/编码器 | 0.5mm² | 双绞屏蔽 |
| PE/接地 | ≥4mm² | 黄绿线 |

**屏蔽与接地注意事项：**
1. 屏蔽层单端接地：脉冲线在驱动器侧、模拟量在 PLC 侧剥 30mm 压入 EMC 线夹，禁止两端都悬空或双端乱接。
2. 电机动力电缆必须用屏蔽电缆，屏蔽层 360° 环接在驱动器 PE 端。
3. 信号线与动力线分线槽，无法避免时用金属隔板隔离。
4. 24V/0V 线径一致，避免压降不平衡；远端传感器就近并 0.1μF 滤波电容。
5. 中间继电器线圈并续流二极管，防止切断瞬间干扰打坏输出点。
6. 柜门活动部分用编织接地带跨接，门上的按钮/屏电缆用屏蔽电缆。
7. 光电、磁性开关类两线制传感器注意漏电流，必要时加假负载电阻。
8. 所有现场线缆两端套号管，与图纸位号一一对应，方便调试期核对。
