# 硬件选型手册

> 适用项目：PLC-Robot-Integration（伺服输送线 + 机器人码垛单元）。本文给出 PLC、伺服、机器人、传感器、人机界面与电气辅件的选型方法、公式与算例，作为同类小自动化项目的通用参考。

## 1. 选型总流程

需求（节拍/精度/负载）→ 点数与功率估算 → 品牌比选（性能、价格、生态、备件）→ 型号确定 → 台账与备件清单。核心原则：**满足需求留 20% 裕量，不为用不上的性能付费，但绝不牺牲安全等级**。

## 2. PLC 选型

### 2.1 点数估算
数字量输入 = 按钮/旋钮 + 传感器 + 反馈信号，乘 1.2 裕量；输出 = 接触器/电磁阀/指示灯，乘 1.3 裕量（输出更容易扩）。本项目实测：DI 14 点、DO 10 点 → 选 S7-1214C（14DI/10DO）正好，扩展留 CPU 本体集成 Profinet 与 2 路 AI。

### 2.2 品牌对比表

| 项目 | 西门子 S7-1200 | 西门子 S7-1500 | 三菱 FX5U | 汇川 Easy |
|---|---|---|---|---|
| 定位 | 小型机 | 中大型机 | 小型机 | 小型机 |
| 最大点数 | ~1000 | 几千 | ~500 | ~300 |
| 运动控制 | 4轴PTO(本体) | 丰富(1500T) | 4轴 | 4轴 |
| 编程语言 | LAD/SCL/FBD | 全部 | LD/ST/FBD | LD/ST |
| 价格 | 中 | 高 | 中 | 低 |
| 生态/资料 | 最丰富 | 丰富 | 丰富 | 增长中 |
| 适用场景 | 小型单机/产线 | 复杂产线/过程 | OEM设备 | 预算敏感 |

**结论与理由**：本项目 1 轴伺服 + 机器人握手 + 触摸屏，S7-1200 的 4 路 PTO、SCL 文本编程（便于 Git 管理）、庞大资料生态最匹配；S7-1500 性能过剩，FX5U 与机器人侧文档联动弱，汇川当时备件渠道不足。

### 2.3 关键校核点
① 输出类型：发脉冲必须选 DC/DC/DC 晶体管输出（继电器寿命与频率都不够）；② 扫描周期：顺控类 <10ms 无压力，高速计数/脉冲走工艺对象与中断，不占扫描；③ 供电：DC24V 消耗预算 ≤ 电源 80%。

## 3. 伺服电机选型（公式法）

### 3.1 转矩计算
负载转矩折算到电机轴：

```
T = (F × v) / (2π × n × η)        直线机构(输送/丝杠)
T = 9550 × P / n                  已知功率反推
J_load = m × (v / (2πn))²         直线运动惯量折算
```

其中 F 含摩擦力 μmg 与轴向负载；启动还需克服加速转矩 `T_a = (J_m + J_load) × α`，总转矩 `T_max = T_f + T_a ≤ 伺服额定×3（瞬时）`。

### 3.2 选型规则
1. **惯量比**：J_load / J_m ≤ 10（高动态场合 ≤5），否则响应震荡。
2. **转速匹配**：机构最高速度折算电机转速 ≤ 额定转速的 90%。
3. **转矩裕量**：连续负载转矩 ≤ 额定的 80%。
4. 频繁启停加刹车电阻；垂直轴带抱闸电机。

### 3.3 本项目算例
输送线：物料+皮带+辊筒折算质量 m=40kg，v=0.4m/s，摩擦系数 0.1，同步带减速比 i=2，滚轮直径 60mm。
F = 0.1×40×9.8 ≈ 39N；折算电机轴向力经减速后约 78N；滚轮转速 n = v/(πD) = 0.4/0.188 ≈ 2.1r/s=127rpm，电机侧 254rpm。
T ≈ 78×0.03/(2×0.85) ≈ 1.4Nm（含效率）——低速大转矩需按转矩选而非功率：选 **750W/2.3Nm 额定** 台达 B2，转矩裕量 >60%，惯量比实测 4.2，合格。

## 4. 机器人选型
1. **负载**：样箱 1.5kg + 吸盘架 3kg ≈ 4.5kg，负载率 4.5/7 ≈ 64%（低于 80% 经验上限，动态裕量充足）→ 选 IRB1200-7；若改用 5kg 箱则负载率超限，应升级 IRB1410。
2. **臂展**：抓取点+垛型最远点距离 ≤ 到位半径的 90%。
3. **防护等级**：粉尘/湿度环境选 IP54 以上本体（铸造选 Foundry Plus）。
4. 控制器生态：IRC5 的 RAPID + RobotStudio 仿真链成熟，适合教学与演示。

## 5. 传感器选型原则
1. **按检测对象**：透明/反光物料避开漫反射光电，改对射或镜反；金属件优先电感接近开关（抗污）。
2. **按输出形式**：与 PLC 输入类型匹配——本项目 PNP（源型）三线制统一，杜绝 NPN/PNP 混接。
3. **按响应速度**：输送线最高 0.5m/s、物料 300mm → 响应 <10ms 即可，E3Z（<1ms）裕量充足。
4. **按环境**：IP67 起步；振动大的限位选金属壳 WL 系列；温度测量用 PT100+变送器进 AI。
5. **接线与抗干扰**：两线制传感器核对漏电流与 PLC 输入门槛；长距离信号用屏蔽双绞、单端接地。
6. **备件通用化**：同类传感器尽量同型号同品牌，减少备件与程序组态差异。

## 6. 人机界面与电气辅件
- 触摸屏：7 寸 MCGS 足够（20 个变量级）；需曲线/复杂报警时上 10 寸或昆仑通态 TI 系列高端型号。
- 开关电源：按总电流 1.5 倍选，本项目 24V 负载约 2.5A → S-100-24（4.5A）。
- 断路器/接触器：主回路按电机额定电流 1.5~2 倍整定，与线缆载流量上级配合；控制回路 2P/6A。
- 线缆：信号 0.5mm² 屏蔽双绞、动力 1.5~4mm²、PE ≥4mm² 黄绿线；柜内号线管两端统一编号。

## 7. 选型核对清单
□ 点数/转矩/负载裕量 ≥20%　□ 输出类型与脉冲需求匹配　□ 安全回路等级确认　□ 通讯口与网段规划　□ 备件可采购性　□ 预算内最优点（性能价格曲线拐点）
