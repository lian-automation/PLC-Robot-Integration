# 现场调试避坑指南

1. 伺服使能（SON/24V）没接通，方向信号给了电机也不动，先查使能线。
2. PLC与机器人IP没配通，务必确认两边在同一网段且子网掩码一致，先ping再跑程序。
3. 限位开关常开/常闭接反，会导致一上电就报限位故障，核对原理图与实物接线。
4. 机器人急停回路串进了PLC安全模块，急停后需复位PLC侧安全区才能再次上电。
5. Profinet设备名未分配或重复，TIA里下载设备名称后再下载硬件组态。
6. RAPID程序的工具/工件坐标系没做TCP标定，抓取位置全偏，先做4点法标定。
7. snap7连接报错多为TSAP或保护等级设置问题，PLC属性里勾选允许外部访问。
8. 气动夹爪磁性开关位置松动，信号时有时无，先固定挡块再调灵敏度。
9. 伺服脉冲方向参数与机械方向相反，改电子齿轮前先低速点动验证。
10. 机器人速度首调时先设v100以下并按住使能死区开关，防止撞机。
