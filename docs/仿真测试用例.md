## 表3：PLC↔机器人联调用例（5 组，RobotStudio 虚拟控制器）

| 用例 | 场景 | 期望结果 |
|---|---|---|
| L1 | 正常握手全流程 10 次 | 1:1 启停，计数正确 |
| L2 | 启动命令粘连（Q0.7 持续为 1） | 仅执行 1 件，不重复启动 |
| L3 | 机器人“允许抓取”30s 不到 | 报握手超时，回待机并可复位 |
| L4 | 机器人“码垛完成”超时 | 报超时，状态机回 0 态 |
| L5 | 急停按下期间按复位 | 不恢复运行，需旋起急停后再复位 |

## 通过判据

表1 全 24 组、表2 全 8 组、表3 全 5 组一次通过（或整改后复测通过），方可判定“阶段二（PLC 单机）/阶段五（联调）”阶段门通过。
