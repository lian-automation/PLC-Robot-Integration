# 码垛单元操作说明书（操作工版）

> 设备：伺服输送线 + ABB 机器人码垛单元　版本：V2.1　日期：2026-08-16
> 本手册为仿真演示项目的配套文档，操作流程与安全要求按真实产线规范编写，供学习、培训与后续实机部署参考。
> 本手册仅面向操作工。维修、编程、接线类操作请找维修人员，严禁自行处理。

## 1. 安全须知

1. 机器人围栏内为**危险区域**，任何情况下不许翻越、伸手；进围栏必须先开安全门（设备自动停）并取走钥匙牌。
2. 急停按钮（红色蘑菇头）任何人都有权按下，四段任一处按下全线下电停机。
3. 不得遮挡光电传感器、不得踩踏电缆线槽。
4. 发现异响、冒烟、焦味、火花：**立即按急停 → 报告班组长 → 疏散到安全位置**。

## 2. 开机流程（每天上班）

1. 穿戴劳保用品，按第 4 节完成**日常点检**并签字。
2. 确认急停按钮全部处于旋起状态、安全门已关闭上锁。
3. 合主回路断路器 QF0 → 合控制空开 QF1 → 合机器人控制柜开关。
4. 等触摸屏启动（约 30 秒）进入主界面；机器人示教器自动进入自动模式（白字“自动”）。
5. 确认屏上：无红色报警、“机器人在线”绿灯、伺服“就绪”。
6. 在屏上把【模式】切到“自动”，按柜面绿色【启动】按钮：
   - 黄灯亮=待机/回原点；绿灯亮=自动运行。
7. 首 3 个循环盯守节拍与垛型正常后，方可离开做其他工作。

## 3. 参数设置（权限：班组长以上，默认密码 123456）

路径：主界面 →【参数设置】→ 输入密码。常用参数如下，其余参数**禁止改动**：

| 参数 | 出厂值 | 允许范围 | 说明 |
|---|---|---|---|
| 目标件数/垛 | 48 | 24~48 | 满垛提示换盘 |
| 电流报警限(A) | 24 | 20~28 | 超过预警 |
| 温度报警限(℃) | 75 | 60~80 | 超过预警 |
| 节拍目标(s) | 20 | 15~30 | 仅统计用 |

参数修改后按【保存生效】，当班记录到交接班本。

## 4. 日常点检表（每班开机前，√/×）

| 序号 | 项目 | 标准 |
|---|---|---|
| 1 | 急停按钮 | 4 处完好、可按下、能旋起 |
| 2 | 安全门锁 | 关闭严密、钥匙在位 |
| 3 | 气源压力 | 0.5~0.6MPa，真空表正常 |
| 4 | 吸盘外观 | 无破损、无粘料 |
| 5 | 输送线 | 无异物、托盘挡块在位 |
| 6 | 触摸屏 | 显示正常、时间正确 |
| 7 | 首件试跑 | 节拍与垛型正常 |
| 8 | 柜面指示灯 | 三色灯指示与状态一致 |

## 5. 正常停机（下班/计划停）

1. 等当前一件码放完成（绿灯期间按【停止】，设备完成本循环后停）。
2. 机器人自动回到 Home 位、伺服使能断开、黄灯亮。
3. 断机器人控制柜开关 → 断 QF1 → 断 QF0（长期停机才断 QF0）。
4. 清理现场，填写交接班记录。

## 6. 紧急停机

**什么时候按**：人员进入危险区风险、设备异响冒烟、机器人路径明显异常、输送线卡料冒火花。
**按了以后做什么**：设备立即停（<0.5 秒）→ 红灯亮蜂鸣 3 秒 → 报告班组长 → 排除问题后按第 7 节复位。
**注意**：急停期间不许强行拖拽机器人手臂、不许复位后立即再启动。

## 7. 故障复位

通用步骤：① 消除故障源（旋起急停/关门/清料/等冷却）；② 按柜面黄色【复位】按钮；③ 屏上报警条变绿消失；④ 重新按【启动】。
复位 2 次仍报警 → 停止尝试，挂“故障停机”牌并报修。

## 8. 常见报警处理表

| 屏显报警 | 原因 | 操作工动作 |
|---|---|---|
| 急停动作 | 急停被按 | 旋起按钮 → 复位 |
| 安全门打开 | 门未关/锁坏 | 关门 → 复位；锁坏报修 |
| 伺服报警 | 过载/驱动器故障 | 断电 5 分钟再上电复位一次，无效报修 |
| 送料超时 | 卡料/光电被挡 | 停机清料、擦光电镜头 → 复位 |
| 握手超时 | 机器人未响应 | 看示教器有无报错；有报错报修 |
| 机器人故障 | 机器人侧报警 | 报修，勿动示教器 |
| 真空未确认 | 吸盘破损/气源低 | 换吸盘/开大气源；掉落的料人工码好 |
| 满垛提示 | 正常提示 | 换托盘 → 按【启动】继续 |

## 9. 交接班要求

交接内容：本班产量/垛数、报警情况、未处理问题、参数改动。工具（钥匙牌、急停锁）当面点清。有“故障停机”牌的设备必须交接清楚原因。
